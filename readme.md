# VetConnect

**Live site:** https://noahmuthama.github.io/vet_connect/

## Description

VetConnect is a website that connects pet owners and livestock owners to licensed veterinary doctors. It helps people book a clinic visit, request a home or farm visit, or call an emergency veterinary unit, all from one place.

## Features

- Book a visit at a clinic near you.
- Request a vet to come to your home or farm.
- Reach the Emergency Veterinary Deployment Unit (EVDU) with one click.
- Meet the vets, from small animal doctors to large animal and exotic specialists.
- Send a message through the contact form and get matched with the right vet.
- Works on phones, with swipeable service cards.

## Built With

- HTML
- CSS

## Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/noahmuthama/vet_connect.git
```

### 2. Open the project folder

```bash
cd vet_connect
```

### 3. Open the website

Double-click `index.html`, or right-click it and choose **Open with** your browser.
